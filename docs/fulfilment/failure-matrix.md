# Fulfilment, Shipping & Replacement Failure Matrix

| Failure Scenario | Authoritative State | Customer Impact | Retry Strategy | Reconciliation | Operator Action | Audit Requirements |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Payment succeeds / fulfilment creation fails** | Order: `PAID`<br>Fulfilment: Missing | Order confirmed; warehouse queue delayed | Queue retry with idempotency key | Background scanner flags `PAID` order without fulfilment | Manual fulfilment trigger if queue dead-letters | Order ID, Payment Ref, Creation timestamp |
| **Fulfilment exists / zero warehouse inventory** | Order: `PAID`<br>Fulfilment: `PAID` with exception | Order confirmed; fulfilment exception notice | Backoff retry as new batches are printed | Inventory stock alert threshold triggered | Expedite printing or reallocate stock | Inventory SKU, Order ID, Exception code |
| **Two fulfilments compete for single QR** | 1st: `RESERVED`<br>2nd: Unique conflict | None (2nd retries next unit) | Immediate retry of eligibility query | Daily active reservation audit | None (handled automatically by D1 unique constraint) | Competing fulfilment IDs, QR ID |
| **Worker crashes after QR reservation** | Reservation: `RESERVED`<br>Fulfilment: `PROCESSING` | None (delayed packing) | Queue message redelivered; reuses reservation | Stale reservation job flags reservations > 4 hours | Inspect warehouse packing queue | Fulfilment ID, Reservation ID, Worker ID |
| **Packing fails / QR sticker physically damaged** | Reservation: `RELEASED`<br>Fulfilment: `PROCESSING` | None | Release damaged QR (`LOST_DAMAGED`); reserve new unit | Reconciliation logs sticker as damaged | Operator selects new sticker in packing UI | Reason code, Actor ID, Old QR ID, New QR ID |
| **Packed / shipment creation fails** | Fulfilment: `PACKED`<br>Shipment: Missing | Parcel ready; tracking delayed | Retry shipping provider dispatch | Scan for `PACKED` fulfilments without shipment > 2 hrs | Manual dispatch override via Admin UI | Fulfilment ID, Courier provider, Error payload |
| **Courier request accepted / response timeout** | Shipment: `PENDING`<br>Courier: Tracking created | Dispatch confirmation delayed | Query tracking API with provider reference | Periodic shipment sync poll | Contact courier support if unresolvable | Request ID, Tracking reference |
| **Shipping webhook duplicated** | Shipment: Target state unchanged | None | Idempotent transition policy rejects duplicate | Webhook event ledger deduplication | None | Webhook Event ID, Provider, Timestamp |
| **Shipping webhook out of order** | Shipment: Retains highest terminal state | None | `shouldIgnoreShipmentEvent()` drops stale downgrade | Event logged for audit | None | Current status, Incoming status |
| **Shipping provider outage** | Fulfilment: `PACKED`<br>QR: Unaffected | Dispatch delayed; QR safety unaffected | Exponential backoff until provider recovers | Monitor carrier status page | Enable fallback manual dispatch mode | Provider code, HTTP status |
| **Notification provider outage (MSG91)** | Shipment: `SHIPPED`<br>Notification: `PENDING` | SMS/WhatsApp delayed; shipment still moves | Phase 11 notification queue retries | Stuck notifications swept by background worker | Check MSG91 balance / delivery reports | Notification Intent ID, Error code |
| **Delivery failed (Customer unreachable)** | Fulfilment: `DELIVERY_FAILED`<br>Shipment: `DELIVERY_FAILED` | Alert sent to customer to coordinate delivery | Courier re-attempts per carrier policy | Monitor failed delivery rate | Customer service calls recipient | Tracking reference, Reason code |
| **Package returned to origin (RTO)** | Fulfilment: `RECEIVED_RTO`<br>Shipment: `RTO_DELIVERED` | Order marked returned; refund/reship policy | Invariant 19: Sticker quarantined; never auto-restocked | RTO review queue | Physical inspection of package seal & scratch code | Fulfilment ID, Inspection report, Operator ID |
| **Replacement approved / zero inventory** | Replacement: `APPROVED`<br>QR: Unallocated | Request approved; dispatch queued | Retry allocation when lot is available | Inventory reconciliation | Alert manufacturing | Request ID, Vehicle ID |
| **Replacement new QR reserved / migration fails** | Replacement: `APPROVED`<br>Old QR: `ACTIVATED` | Existing QR remains active on vehicle | Transaction rollback; retry migration | Audit log verification | Inspect database error | Request ID, Old QR, New QR |
| **Old QR replaced / new assignment fails** | Handled in atomic batch | State rolled back to pre-migration | Retry atomic migration | Consistency scanner verifies 1:1 active mapping | Manual review if repeated failures | Old QR, New QR, Error detail |
| **Replacement completed / notification fails** | Replacement: `COMPLETED`<br>Notification: `PENDING` | Notification delayed; QR already migrated | Asynchronous retry via Phase 11 queue | Dead-letter queue alert | None | Intent ID, Notification channel |
